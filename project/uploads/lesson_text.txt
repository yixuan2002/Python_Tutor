[Heading2] 0-1  什麼是程式語言？
電腦非常聰明，但它只聽得懂一種語言：0 和 1 組成的機器碼。程式語言就是「人和電腦之間的翻譯官」——我們用接近人類語言的方式寫指令，電腦再把它翻譯成自己看得懂的格式。
沒有程式語言（機器碼）
有程式語言（Python）
01110000 01110010...
電腦看得懂，人看不懂 😵
print("Hello!")
人看得懂，電腦也能執行 ✅
老師互動提示
問學生：「你覺得電腦怎麼知道按下 A 鍵要顯示字母 A？」

重點不是答對，而是讓學生開始思考「電腦是怎麼運作的」。

📖 第一部分：概念講解（8-20 分鐘）
[Heading2] 1-1  變數
變數就像是一個有名字的「盒子」，用 = 把值放進去：
name      = "小明"   # 字串：文字，要加引號
age       = 12       # 整數：沒有小數點
score     = 99.5     # 浮點數：有小數點
is_winner = True     # 布林值：只有 True 或 False
命名規則（快速版）
只能用英文、數字、底線（_）；不能有空格；不能以數字開頭。
大小寫有差：Name 和 name 是不同的變數。

[Heading2] 1-3  print() 與 f-string
print() 是 Python 內建函式，把東西顯示在螢幕上。搭配 f-string 可以把變數直接嵌入文字：
name = "小明"
age  = 12
print("Hello, Python!")         # 輸出純文字
print(f"我叫 {name}，今年 {age} 歲")  # f-string：變數自動代入
print(f"明年我 {age + 1} 歲")   # {} 裡可以直接做運算
⚠️ input() 的型別陷阱（快速提醒）
name = input('你叫什麼？')  → 回傳的一定是字串（str）
要做數學運算，需先轉換：age = int(input('幾歲？'))
💡 第二部分：例題示範（20-32 分鐘）
[Heading2] 例題：自我介紹程式
老師講解方式：逐行讀程式碼，每一行都問學生「你覺得這行在做什麼？」，不要直接說答案。
# 例題：自我介紹
# （# 是注解，電腦會忽略，是給人看的說明）
name  = input("你叫什麼名字？ ")
age   = int(input("你幾歲？ "))   # input 回傳字串，int() 轉成整數
grade = input("你幾年級？ ")
print("───────────────────")
print(f"大家好！我叫 {name}。")
print(f"我今年 {age} 歲，就讀 {grade} 年級。")
print(f"再過一年我就 {age + 1} 歲了！")
print("───────────────────")
執行結果範例：
你叫什麼名字？ 小明
你幾歲？ 12
你幾年級？ 六年級
───────────────────
大家好！我叫 小明。
我今年 12 歲，就讀 六年級。
再過一年我就 13 歲了！
───────────────────
